# Deskripsi
Repository ini dibuat untuk menyimpan dan mengelola dokumentasi serta catatan kegiatan selama mengikuti workshop.

# Apa itu repository?
Repository ini merupakan wadah terpusat yang dikembangkan untuk menyimpan dan mengelola dokumen, berkas proyek, serta rancangan program kerja mahasiswa yang berfokus pada terciptanya lingkungan kampus yang sehat, inklusif, serta wadah pengembangan minat, bakat, dan inovasi dengan dukungan penuh dari institusi.

# Tujuan repository 
Repository ini bertujuan untuk mendokumentasikan, mengarsipkan, serta mempermudah akses terhadap konsep program kerja dan inisiatif strategis   kemahasiswaan. Selain itu, repository ini berguna sebagai acuan transparan dalam merancang strategi pengembangan minat, inovasi, dan advokasi dukungan kampus secara berkelanjutan.

# Rangkuman materi day 1
Rangkuman materi yang dipelajari pada sesi ini meliputi:

- Teknik Prompting dan Pemanfaatan AI: Eksplorasi kerangka prompt yang terstruktur (Role, Task, Context, Format) guna mendukung percepatan pembuatan sistem web dengan bantuan         kecerdasan buatan.  
     
     
- Pengendalian Versi (Git & GitHub): Pemahaman mendalam mengenai alur penanganan repositori (direktori aktif, staging, repositori lokal/remote), eksekusi perintah dasar               terminal (git init, add, commit, push), serta tata kelola pembaruan program pada GitHub.

# Pendapat pribadi tentang hari ini
Sesi materi hari ini sangat interaktif dan memberikan wawasan praktis. Latihan langsung mengenai integrasi alur kerja antara perintah Git dengan platform GitHub membantu saya memahami proses dokumentasi siber dan pengembangan perangkat lunak modern secara nyata.
